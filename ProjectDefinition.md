Project Definition and Scope
---

# Objective
A static web application delivering a twenty five question psychological assessment. The logic will cross reference Myers Briggs, the Big Five Inventory, and the Enneagram to assign users one of twelve overarching archetypes.

# Technical Constraints
The application will execute entirely in the browser to ensure zero hosting costs through GitHub Pages. There will be no backend database. State will be managed locally in the browser memory.

# Core Features
The interface will present a seamless question progression. Once complete, the algorithm will calculate the dominant traits and route the user to one of twelve final pages. Each result page will feature a dedicated archetype image, a written analysis, and a download button. The download function will capture the specific document object model element containing the text and image, converting it to a downloadable graphic for the user.

# Development Phasing
We will leverage KIRO in Spec Mode. This forces the agent to write a requirements document, a design document, and a task list before generating any actual code. If the credit limit is reached, this structured output can be seamlessly ported to standard Visual Studio Code where Gemini can complete the remaining tasks.
